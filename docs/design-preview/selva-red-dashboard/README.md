# selva Red Dashboard

Standalone interactive red/black direction preview. Open `selva Red Dashboard.html` locally. No server, API, account, broker or device access. All device and event content is explicitly demo data.

Figma reference: https://www.figma.com/make/szPdjI5vrr5ULQVqTur7kB/Red-Dashboard
The Figma plugin returned source-resource links for App.tsx and index.css, but resource reads failed with Unknown resource. This preview therefore is a concept based on the requested visual direction, not a source-derived or visually verified reproduction.

Black navigation, red #FF0000 accents, hover/press button transitions, responsive mobile drawer, filtered system-event timeline and a locally simulated PING acceptance/response sequence. Respects reduced-motion preferences. Existing SELVARITHIK wordmark asset reused.

Preview created separately from production templates/firmware. Wi-Fi, MQTT profiles and sensor settings were not accessed or changed.
