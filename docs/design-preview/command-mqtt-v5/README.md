# Design V5

Preview only; production code and device settings unchanged.

Sent command cards show Source, Target, Priority, Timeout, Retries, Dispatch, ACK, Execution, Created, configured-parameter disclosure, command ID, error, timestamp and Retry. Parameter contents remain collapsed. Sent-card background is cream #FFF7EB. Failure badges, execution FAILED and error text use exactly #FF0000, matching the top header. ACK stays status/time only; response remains compact. Retry is a static preview label, not a live action. MQTT design remains unchanged.
