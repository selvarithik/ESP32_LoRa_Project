Static front-end dependency inventory
Audit date: 2026-10-09
Branch: shell-hardening-mobile-search-2026

PURPOSE / LIMITS
This is a source audit of the existing Flask/Jinja frontend before retiring any
legacy UI layer. It inventories page routes, templates, page controllers, API
paths and the main DOM hooks. URLs with <id> segments stand for values already
inserted by the existing controller. Some controllers build element references
through helpers or generated row IDs; those are called out rather than guessed.
This source audit does not claim that a visual browser pass at all breakpoints
has already been completed.

Shared dependencies:
- app.js owns the existing API helpers, HTML escaping, toast helper, clock,
  connection indication, active nav, light-theme initialization, sidebar
  collapse preference and mobile drawer behavior.
- modern-shell.js owns the new page-search dialog, Ctrl/Cmd+K, up/down result
  selection, Enter navigation, Escape close, focus trap and focus restoration.
- redesign-v3.js remains loaded: it enables data-v3-tab/data-v3-panel tabs on
  Communication and Firmware, maps legacy Logs filter IDs to IDs expected by
  logs.js, marks System settings sections and draws mesh topology on the
  existing gateway:mesh event.
- ui-overhaul-2026.js remains loaded for active-page aria-current, quick search
  focus, Escape fallback and horizontally scrollable table wrappers.
- Do not remove an old CSS/JS asset until all its selectors and page dependencies
  are verified. Legacy shared CSS layers are intentionally retained below the
  modern shell to avoid breaking page-specific v3 components.
